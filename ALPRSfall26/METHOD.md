# Method

This repository preserves a public research record about automated license
plate recognition (ALPR) and related surveillance practices. It is a source
collection, not legal advice and not an official statement by any institution
unless that affiliation is separately confirmed.

## Source handling

- Prefer primary materials: statutes, directives, court opinions, agency
  records, and source-authored reports.
- Record the source date, publisher or issuing body, access date, and stable
  URL when available.
- Treat live search pages as discovery aids, not as archived evidence. Save a
  permitted snapshot or record identifier before making a reproducibility
  claim.
- Do not describe a document as current law without checking its amendment,
  effective-date, and supersession history.
- Keep quotations distinct from paraphrases and identify the document being
  summarized. Add page or paragraph pinpoints before calling a holding
  verified.

## Release review

Before a document enters GitHub or the approved Drive workspace, confirm that
it is permitted for public release, contains no incident report or police
record, and contains no unnecessary personal or sensitive information. Do not
upload sensitive material for later review. Check the file and its metadata,
not just the filename.

For Drive-backed catalog entries, publish only the individual reviewed file
link. Do not publish a working-folder link. Record the relationship between a
Drive copy and the Git snapshot with a date and checksum when both are meant
to represent the same version.

## Uncertainty

Use explicit markers such as `pin_read: no`, `current-law-verified: no`, and
`source-status: discovery-only` when a claim or source has not been checked.
Open questions belong in the relevant README rather than being presented as
findings.
