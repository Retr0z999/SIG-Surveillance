# ALPRS Fall 2026

This is the working research record for the Fall 2026 automated license plate
recognition and surveillance project.

## Project structure

- `authorities/` contains the legal materials used to ground the research.
	Its `cases/`, `directives/`, and `statutes/` READMEs explain the relevance
	of each PDF in those folders.
- `data/` contains datasets and data documentation.
- `records/` contains collected records and supporting materials.
- `reports/` contains project reports and analysis.
- `requests/` contains public-records requests and related correspondence.
- `sources/` contains empirical sources, reports, testimony, and vendor
	materials.

The public document catalog is available at
<https://retr0z999.github.io/SIG-Surveillance/>. The catalog links to the
current Google Drive copies, while the PDFs committed in this repository form
the historical, auditable record.
