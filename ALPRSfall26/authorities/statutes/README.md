# Statutes

This folder contains a historical statutory source relevant to public-records
and transparency research. It is not represented as the current law without a
separate version check.

## Documents

- [OPRA(2001).pdf](OPRA%282001%29.pdf): A 2001 copy of New Jersey's Open Public
    Records Act. It is retained as a historical reference; amendments, current
    codification, exemptions, and current procedures require verification before
    relying on it. `current-law-verified: no`.
