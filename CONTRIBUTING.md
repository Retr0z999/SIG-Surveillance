# Contributing

This repository is public. Treat every file committed here or uploaded to the
project Google Drive folder as potentially public and permanent.

## Absolute exclusion

Do **not** upload or commit incident reports, police records, medical or
psychiatric records, personally identifying information, or any document that
identifies a minor. This prohibition applies to drafts and working files in
Google Drive as well as to Git commits. In particular, Dumont incident
reports, including copies kept on a contributor's machine, never enter this
repository or its Drive folder.

If a source contains sensitive material, do not upload it for later review.
Ask the project lead for a redaction decision using a description that omits
the sensitive content.

## Before adding a document

1. Confirm that the document is public or that the project has permission to
   publish it.
2. Remove personal information that is not necessary for the research record.
3. Check that no minor's identity, medical information, psychiatric history,
   address, phone number, or other sensitive personal data remains.
4. Use a descriptive filename and place the file in the matching
   `ALPRSfall26/` authority, record, request, source, or report folder.
5. Add a short relevance note to the folder README when the document is a
   primary source.

## Google Drive and GitHub

Google Drive is for approved collaborative working copies. GitHub is the
public historical record. A Drive link in `ALPRSfall26/docs/documents.json`
must point only to an approved document, never to an unreviewed folder of
working files. Do not use Drive permissions as a substitute for redaction.

Before publishing a Drive-backed catalog entry, verify the file's sharing
permission and confirm that opening it in a private browser window does not
expose unrelated files.
